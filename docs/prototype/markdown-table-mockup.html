ECDI Fake Harness · Markdown 表格渲染原型 方案 B 原型

① 渲染期解析与无损存储

存储与传输保持 Markdown 纯文本原文，journal/context 不受影响。由 Transcript.cpp 导出纯函数 ParseMarkdownSegments(text) 识别纯文本与管道表格。

② 版心与超宽保护

严格遵守版心上限 TranscriptLayoutWidth = min(宽, 760)。当表格列数较多超宽时，通过自绘容器支持局部水平平滑横向滚动，不破坏消息对齐。

③ 终态切分原则

表格切分只在 block_end 到达后执行结构化网格排布。流式中途保持等宽纯文本呈现，杜绝错乱抖动半态。
